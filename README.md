# Виртуальный двойник кампуса УрФУ, а точнее ИРИТ-РТФ
Движок - Unity 6000.3.27f1. Правила именования: https://www.c-sharpcorner.com/article/C-Sharp-coding-standards-and-naming-conventions

## Директории в Assets
При названии файла и директории используется **PascalCase**.

### Art
Для моделей, текстур и материалов. Art делится на категорий объектов (например, Environment, Furniture, Buildings). Они делятся на директории групп объектов (например, Tables, Chairs) или директории самих объектов, если они уникальны. Директории групп объектов делятся на сами объекты (например, Table1). В директории объекта и будут храниться текстуры, материалы и модели для этого объекта.

### Audio
Для аудиофайлов. Делится на SFX (для звуков) и Music (для музыки). SFX делится по категориям (например, Environment, Furniture, Player и пр).

### Prefabs
Для префабов. Делится на категории объектов (например, Particles, Player, Furniture). В директориях категорий могут быть директории групп объектов (например, Tables) или префабы самих объектов, если они уникальны.

### Scenes
Для сцен. В корне Scenes хранятся только сцены для билда. Тестовые сцены для разработки - в поддиректории Test. Test делится по членам команды.

### Scripts
Для скриптов. Делится на категории объектов (например, Player, Environment). Внутри них деление произвольное.

### ScriptableObjects
Для ScriptableObject. Делится по группам объектов, объединённых одни классом, наследуемым ScriptableObject.

### Shaders
Для скриптов и графов шейдеров. Деление произвольное.

### Lights
Для файлов конфигурации света. Деление произвольное.

## Совместная работа

### Unity
В Unity каждый работает в своей тестовой сцене. Если наработки нужно объединить, кто-то один переносит изменения в общую сцену.

### Ветки
Все работают в разных ветках. Весь код нужно мёрджить в ветку dev. Ветка main - для релиза, она мёрджится только с dev. Напрямую в main и dev ничего пушить нельзя.
Для названия веток используется **snake-case**. Если ветка - для фичи, она называется feature/название-фичи. Если для исправления бага, то bugfix/что-нужно-исправить. Если это импорт ассетов, то assets/название-ассетов (например, assets/first-floor или assets/tables). Остальные имена произвольны.

### Коммиты
Названия начинаются с глаголов во втором числе, например "imports tables assets".
